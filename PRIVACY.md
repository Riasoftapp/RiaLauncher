# RiaLauncher Privacy Policy

Last updated: 2026-08-29

RiaLauncher is a desktop application launcher for Windows. It runs entirely on your
own computer and does not require an account, a registration or a login.

## Data we collect

RiaLauncher does not collect, store or transmit any personal data. There is no
telemetry, no analytics, no crash reporting, no advertising and no tracking of any
kind. Usage of the application is never reported back to the developer.

## Data stored on your device

The application keeps its configuration and your launcher items locally on your
computer:

- **Settings** - interface language, view mode, launch behaviour and similar preferences
- **Launcher items** - the names, file paths and icons of the shortcuts you add
- **Logs** - local troubleshooting log files

This data never leaves your machine. You can delete it at any time by removing the
application's data folder or by uninstalling the application, which removes all files
it installed.

## Network access

The only network communication is the update check. When you start an update check
manually, RiaLauncher queries the public GitHub repository
<https://github.com/Riasoftapp/RiaLauncher> for the latest release information. This
request contains no personal data and no information about the contents of your
launcher. If a new version is available, the update files are downloaded from GitHub
Releases.

## Third parties

No third-party analytics, advertising or tracking components are embedded. The
installer is built with Inno Setup and contains no bundled third-party software,
toolbars or offers.

## Children's privacy

RiaLauncher is not directed at children and does not knowingly collect any
information from anyone.

## Changes to this policy

If this policy changes, the updated version will be published at this same URL.
